---

`npm run render-sample -- ${1:-gray}` 를 실행한 뒤:

1. 자동 검수 결과(통과/경고/위반)를 요약해서 알려줘.
2. `out/sample/` 의 표지(slide-01), 본문 한 장, 요약(slide-09), CTA(slide-10)를 실제로 읽어서
   글자가 잘리거나 카드 밖으로 넘치는 곳이 없는지 눈으로 확인해줘.
3. 문제가 있으면 어느 슬라이드의 어떤 값을 고쳐야 하는지 구체적으로 알려줘.

체크리스트 09(잘림·낮은 화질 금지)는 코드로 판정할 수 없어서 이 눈 검수가 유일한 방어선이야.
