# 발행 전 체크리스트 30 — 자동화 매핑

도달·저장을 만드는 30개 항목을 이 봇이 어디까지 자동으로 지키는지 정리한 표다.
**자동**은 코드가 강제하는 것(위반하면 게시가 막히거나 렌더가 실패), **반자동**은 코드가 도와주지만 사람이 최종 확인하는 것,
**수동**은 계정 운영자가 직접 해야 하는 것이다.

규칙 값을 바꾸려면 `data/brand-config.json` 을 고친다. 검수 로직은 `src/quality/checklist.js` 에 있다.

## 자동 검수 통과 못 하면

`src/quality/checklist.js` 의 error 가 남아 있으면 봇은 **게시하지 않는다.**
Gemini에 위반 목록을 돌려주며 최대 3번까지 다시 쓰게 하고, 그래도 안 되면 실행이 실패한다(Actions에서 알림).

규칙이 과하다고 판단되면 검수기를 끄지 말고 `data/brand-config.json` 의 기준값을 조정한다.
