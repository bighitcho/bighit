## 1. 잘되는 콘텐츠 패턴 분석

여기 제 최근 게시물 10개의 조회수, 저장 수, 공유 수, 댓글 수, DM 수, 링크 클릭 수, 문의 수, 실제 판매 수입니다.

```
[게시물별 데이터 붙여넣기]
```

다음 기준으로 분석해줘.

1. 조회수가 잘 나온 게시물의 공통 주제와 후킹 방식
2. 저장과 공유가 많이 발생한 게시물의 공통점
3. 댓글과 DM을 많이 만든 게시물의 공통점
4. 실제 문의와 판매를 만든 게시물의 공통점
5. 조회수는 높지만 전환이 낮은 게시물
6. 조회수는 낮아도 문의나 판매 전환이 높은 게시물
7. 성과가 좋은 게시물들이 같은 유형인지, 서로 다른 유형인지
8. 앞으로 반복해야 할 콘텐츠 유형
9. 이제 그만 올리거나 비중을 줄여야 할 콘텐츠 유형

분석 결과를 바탕으로 이미 잘 먹히는 방향의 새로운 콘텐츠 아이디어 10개를 제안해줘.

각 아이디어에는 다음 내용을 포함해줘.

- 콘텐츠 주제
- 타깃 독자
- 후킹 문구
- 카드뉴스 또는 릴스 구성
- 독자가 얻게 되는 결과
- 적합한 CTA
- 기대되는 성과 지표

성과가 없는 콘텐츠는 돌려 말하지 말고 단호하게 알려줘.

## 2. 판매와 문의를 만드는 캡션 작성

다음 카드뉴스 또는 릴스 내용을 바탕으로 인스타그램 캡션을 작성해줘.

```
[슬라이드 또는 영상 내용 붙여넣기]
```

작성 조건은 다음과 같아.

1. 표지 문구와는 다른 후킹으로 시작해줘.
2. 첫 2문장 안에 독자가 계속 읽어야 할 이유를 제시해줘.
3. 짧은 개인 경험, 실제 사례 또는 결과를 1개 넣어줘.
4. 독자가 겪는 문제를 구체적으로 짚어줘.
5. 정보만 나열하지 말고 문제, 원인, 해결 방법 순서로 구성해줘.
6. 지나친 과장이나 독자에게 결과를 보장하는 표현은 사용하지 마.
7. 확인되지 않은 수익 숫자는 넣지 마.
8. '무조건', '보장', '누구나', '100%'라는 표현은 사용하지 마.
9. 문장은 짧고 읽기 쉽게 써줘.
10. 줄바꿈을 충분히 사용해줘.
11. 마지막에는 댓글, 저장, 공유, DM 또는 링크 클릭 중 가장 적합한 행동을 유도해줘.
12. 무료 자료를 제공하는 경우 특정 키워드를 댓글로 남기게 하는 부드러운 CTA로 마무리해줘.
13. 전체 분량은 120~250단어 이내로 작성해줘.
14. 광고 문구처럼 딱딱하지 않고 실제 사람이 말하는 것처럼 써줘.

마지막에 다음 항목도 함께 작성해줘.

- 캡션 제목 3개
- CTA 문구 3개
- 고정 댓글 문구 1개
- 관련 해시태그 15개

## 3. 하나의 후킹을 7장 카드뉴스로 만들기

다음 후킹을 7장짜리 인스타그램 카드뉴스로 구성해줘.

```
[후킹 문구 붙여넣기]
```

타깃 독자:

```
[타깃 독자 입력]
```

콘텐츠 목적:

```
[정보 제공 / 저장 유도 / 팔로우 증가 / 댓글 유도 / DM 문의 / 상품 판매 중 선택]
```

다음 원칙을 지켜줘.

- 1장은 스크롤을 멈추게 하는 후킹으로 작성해줘.
- 2장은 독자가 겪는 문제 또는 흔한 오해를 보여줘.
- 3장은 그 문제가 생기는 핵심 원인을 설명해줘.
- 4장은 첫 번째 해결 방법을 제시해줘.
- 5장은 두 번째 해결 방법 또는 실제 적용 사례를 제시해줘.
- 6장은 핵심 내용을 요약하거나 독자가 바로 실행할 체크리스트를 제시해줘.
- 7장은 콘텐츠 목적에 맞는 CTA로 마무리해줘.

각 슬라이드에는 하나의 핵심 내용만 넣어줘.

각 슬라이드 문장은 최대 20단어 이내로 작성해줘.

중학생도 바로 이해할 수 있을 정도로 쉽고 명확하게 써줘.

추상적인 표현보다 구체적인 행동과 사례를 사용해줘.

내용이 약하면 억지로 채우지 말고 과감히 삭제하거나 더 강한 내용으로 교체해줘.

카드뉴스 작성 후 다음 내용도 함께 제공해줘.

- 표지 후킹 대안 5개
- 슬라이드별 이미지 또는 디자인 방향
- 카드뉴스 전체 캡션
- CTA 문구 3개
- 해시태그 15개

## 4. 스크롤을 멈추게 하는 후킹 만들기

바이럴 카드뉴스와 직접반응형 콘텐츠를 연구하는 전문 카피라이터처럼 행동해줘.

내 타깃 독자는 다음과 같아.

```
[타깃 독자 입력]
```

주제는 다음과 같아.

```
[주제 입력]
```

이 콘텐츠의 목적은 다음과 같아.

```
[조회수 / 저장 / 공유 / 팔로우 / 댓글 / DM / 문의 / 판매 중 선택]
```

표지용 후킹 15개를 만들어줘.

각 후킹은 다음 조건을 지켜줘.

1. 최대 8단어 이내로 작성해줘.
2. 이모지는 사용하지 마.
3. 어렵거나 추상적인 단어는 사용하지 마.
4. 한눈에 뜻을 이해할 수 있게 써줘.
5. 독자가 얻는 이익이나 피할 손실이 드러나게 해줘.
6. 지나친 과장과 허위 표현은 사용하지 마.
7. 서로 비슷한 문장을 반복하지 마.

다음 후킹 유형을 골고루 섞어줘.

- 강한 주장형
- 흔한 실수 경고형
- 아무도 알려주지 않는 비밀형
- 비포 앤 애프터형
- 숫자형
- 질문형
- 반전형
- 금지형
- 체크리스트형
- 호기심 자극형

15개를 작성한 후 가장 좋은 후킹 3개를 선정해줘.

선정한 3개에 대해서는 다음 내용을 설명해줘.

- 왜 시선을 끄는지
- 어떤 독자에게 효과적인지
- 어떤 카드뉴스 내용으로 연결하면 좋은지
- 과장되거나 오해를 부를 가능성은 없는지

마지막으로 선정한 1위 후킹을 더 강하게 다듬은 최종 문구 3개를 추가로 제안해줘.

## 5. AI에게 내 말투 학습시키기

아래는 제가 직접 작성한 글 중 반응이 좋았던 캡션과 게시물 5개입니다.

```
[내가 작성한 글 5개 붙여넣기]
```

이 글들을 바탕으로 제가 글을 쓰는 방식을 분석해줘.

단순히 내용을 요약하지 말고 다음 요소를 구체적으로 분석해줘.

1. 평균 문장 길이
2. 글을 시작하는 방식
3. 첫 문장에서 사용하는 후킹 방식
4. 자주 반복하는 단어와 표현
5. 문장 끝맺음 방식
6. 질문을 사용하는 방식
7. 독자에게 말을 거는 방식
8. 정보와 감정을 섞는 비율
9. 개인 경험을 넣는 위치와 방식
10. 돈, 성과, 실패, 신념을 표현하는 방식
11. 줄바꿈과 문단 구성 습관
12. 강조할 때 사용하는 표현
13. CTA를 넣는 방식
14. 사용하지 않는 표현 또는 피해야 할 말투
15. 전체적인 분위기와 캐릭터

분석 결과를 제가 확인할 수 있도록 다음 형식으로 정리해줘.

- 핵심 말투 특징 5가지
- 자주 사용하는 문장 구조 5가지
- 자주 사용하는 표현 10개
- 피해야 할 표현 10개
- 글 작성 규칙 10개
- 줄바꿈 규칙
- 도입부 작성 공식
- 본문 전개 공식
- 마무리와 CTA 공식

그다음 이 말투를 재현할 수 있는 '나만의 글쓰기 스타일 가이드'를 만들어줘.

앞으로 내가 새로운 주제를 주면 위 스타일 가이드를 적용해 글을 작성해줘.

다만 원문의 내용을 그대로 복사하지 말고, 말투와 구조적 특징만 반영해줘.

내 말투가 어색하거나 전달력이 떨어지는 부분은 그대로 따라 하지 말고, 자연스러움과 가독성을 유지하면서 개선해줘.

## 6. 인스타그램 프로필 진단 및 개선

당신은 인스타그램 프로필 최적화와 퍼스널 브랜딩 전문가입니다.

사업가 또는 크리에이터의 프로필을 전체적으로 진단하고, 프로필 방문자가 팔로워, 문의 고객, 구매 고객으로 전환될 수 있도록 이름, 소개글, 핵심 가치, 신뢰 요소, CTA를 다시 설계해줘.

현재 프로필 정보는 다음과 같아.

```
계정 이름: [입력]
프로필 이름: [입력]
소개글: [입력]
주요 콘텐츠: [입력]
타깃 고객: [입력]
제공하는 상품 또는 서비스: [입력]
대표 경력과 성과: [입력]
연결 링크: [입력]
```

다음 기준으로 진단해줘.

1. 프로필 이름만 보고 전문 분야를 바로 알 수 있는지
2. 검색 키워드가 적절히 포함되어 있는지
3. 첫 줄에서 누구를 돕는지 명확한지
4. 어떤 문제를 해결하는지 보이는지
5. 독자가 얻는 결과가 구체적인지
6. 나만의 방법이나 차별점이 드러나는지
7. 경력, 성과, 고객 사례 등 신뢰 요소가 있는지
8. 소개글이 추상적이거나 자기소개에만 머물러 있지 않은지
9. 방문자가 다음에 무엇을 해야 하는지 명확한지
10. 링크를 눌러야 할 이유가 충분한지
11. 전체 문장이 짧고 읽기 쉬운지
12. 팔로우, 문의, 구매 전환 가능성이 높은지

각 항목을 다음 형식으로 평가해줘.

- 현재 문제점
- 개선 방향
- 수정 문구
- 수정 이유

그다음 최종 프로필 문구를 5가지 버전으로 작성해줘.

1. 전문가형
2. 친근한 퍼스널브랜드형
3. 상품 판매형
4. 상담 및 문의 유도형
5. 콘텐츠 팔로우 유도형

프로필 작성 조건은 다음과 같아.

- 프로필 이름은 공백 포함 최대 64자
- 소개글은 전체 150자 이내
- 4줄 이내로 구성
- 첫 줄은 핵심 가치 제안
- 둘째 줄은 방법 또는 차별점
- 셋째 줄은 경력, 성과 또는 신뢰 요소
- 넷째 줄은 명확한 CTA
- 추상적인 표현보다 구체적인 단어 사용
- 검색성과 가독성, 전환율을 함께 고려
- 과장된 성과나 확인되지 않은 표현은 사용하지 않기

마지막에는 가장 추천하는 최종 프로필 1개를 선정하고 선정 이유를 설명해줘.

## 7. 30일 콘텐츠 기획표 만들기

당신은 인스타그램 콘텐츠 전략가이자 퍼스널 브랜딩 전문가입니다.

아래 정보를 바탕으로 30일 동안 게시할 콘텐츠 계획을 만들어줘.

```
내 전문 분야: [입력]
내 타깃 독자: [입력]
내가 판매하거나 연결하려는 상품·서비스: [입력]
내 계정의 주요 목적: [조회수 / 팔로워 증가 / 신뢰 형성 / 문의 / 판매 중 입력]
내가 잘 다룰 수 있는 주제: [입력]
내가 피하고 싶은 주제: [입력]
최근 성과가 좋았던 콘텐츠: [입력]
내 말투와 분위기: [입력]
사용 가능한 콘텐츠 형식: [카드뉴스 / 릴스 / 사진 / 스토리 / 라이브 등 입력]
```

30일 콘텐츠는 다음 비율로 구성해줘.

- 문제 해결형 콘텐츠 30%
- 전문성과 신뢰를 만드는 콘텐츠 20%
- 공감과 관계 형성 콘텐츠 20%
- 사례와 경험 콘텐츠 15%
- 상품과 서비스 연결 콘텐츠 15%

각 날짜별로 다음 항목을 표로 작성해줘.

- 날짜
- 콘텐츠 유형
- 주제
- 타깃 독자의 문제
- 표지 후킹
- 핵심 내용
- 카드뉴스 또는 릴스 구성
- CTA

- 기대 성과
- 재활용 가능한 플랫폼

비슷한 주제를 반복하지 말고, 30개의 콘텐츠가 하나의 브랜드 메시지로 연결되게 구성해줘.

판매 콘텐츠만 연속해서 배치하지 말고 정보, 공감, 신뢰, 사례, 판매 콘텐츠가 자연스럽게 이어지게 해줘.

마지막에는 다음 내용도 정리해줘.

- 30일 핵심 콘텐츠 시리즈 5개
- 가장 성과가 기대되는 콘텐츠 5개
- 저장을 유도할 콘텐츠 5개
- DM과 문의를 유도할 콘텐츠 5개
- 상품과 자연스럽게 연결할 콘텐츠 5개
- 30일 동안 반복해서 사용할 CTA 문구 10개

## 사용 팁

- 프롬프트 1 → 4 → 3 → 2 순서로 이어서 쓰면 "데이터 분석 → 후킹 개발 → 카드뉴스 구성 → 캡션 작성"까지 하나의 흐름으로 콘텐츠 제작이 끝난다.
- 프롬프트 5는 초반에 한 번만 실행해서 스타일 가이드를 만들어두면, 이후 모든 캡션 작성에 톤앤매너 기준으로 재사용할 수 있다.
- 프롬프트 6, 7은 월 1회 또는 분기 1회 정도로 점검하는 용도로 사용한다.
- `src/generator/gemini.js` 의 카드뉴스 생성 프롬프트를 개선할 때도 이 문서의 후킹/구성 원칙(프롬프트 3, 4)을 참고할 수 있다.
