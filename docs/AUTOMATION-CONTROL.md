> 인수인계 문서입니다. 마지막 갱신: 2026-08-31

  대기 중 — 충전 후 해당 세션에 "재시도해"라고 답하면 이어서 진행됨 (16편 + 썸네일 15장 대기).

## 2. 매일 아침 이렇게 흘러갑니다 (사장님이 할 일)

1. **08:00 KST** — Routine이 자동으로 깨어나 글 3편을 쓰고 썸네일까지 만들어 **초안(비공개)** 으로 올림.
2. 폰의 Claude 앱으로 **미리보기 3장이 도착**함.
3. 사장님은 폰에서 글마다 답장: **"발행"** / **"수정: ○○ 고쳐줘"** / **"스킵"**.
4. "발행"이라고 한 글만 공개 발행됨. **승인 없이 공개 발행되는 글은 없음.**

외근 중이어도 폰만 있으면 되고, 데스크탑 프로그램은 켤 필요 없습니다.

## 3. 세션이 "기억을 못 하는" 이유 (중요)

- claude.ai/code 에서 **새 창(새 세션)을 열면 완전히 새로운 대화**가 시작됩니다.
  이전 세션·일반 claude.ai 챗의 대화 내용은 넘어오지 않습니다.
- 그래서 **하던 일은 새 세션을 만들지 말고, 세션 목록에서 기존 세션을 눌러 이어서** 대화해야 합니다.
- 세션 목록의 **"입력 필요"** = 그 세션이 사장님 답을 기다리며 멈춰 있다는 뜻입니다.
  (예: ISMI 세션은 Gemini 충전 후 "재시도해" 답장을 기다리는 중)
- 새 세션을 만들 때 고르는 **저장소/브랜치 칩은 그 세션에만 적용**되며, 마지막 선택이 기본값으로
  기억됩니다. 기존 세션을 이어서 쓰면 다시 고를 필요가 없습니다.
- 세션과 무관하게 **매일 도는 일은 Routine(예약 작업)이 담당**하므로, 창을 열어두지 않아도 돌아갑니다.

## 4. 켜고 끄는 법

아무 Claude Code 세션에서나 말로 지시하면 됩니다:

- 끄기: "블로그 반자동 일일 발행 루틴 꺼줘"
- 켜기: "블로그 반자동 일일 발행 루틴 켜줘"
- 즉시 1회 실행: "일일 발행 루틴 지금 바로 한 번 실행해줘"

## 5. 자주 막히는 지점

| 증상 | 원인 | 해결 |
|---|---|---|
| 아침 발행이 안 옴 | Claude 사용량/지출 한도 초과 | claude.ai/settings/usage 에서 한도 확인·상향 |
| ISMI 복구 멈춤 | Gemini API 선불 소진 (429) | Google AI Studio에서 충전 → 해당 세션에 "재시도해" |
