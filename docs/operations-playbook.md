# 운영 플레이북

봇이 대신할 수 없는 부분, 그리고 봇을 어떤 전략 위에서 돌리는지 정리한 문서다.

## 1. 3대 콘텐츠의 역할이 다르다

| | 노출 대상 | 역할 | 빈도 | 이 봇이 하는 일 |
|---|---|---|---|---|
| 릴스 | 비팔로워 먼저 | 신규 유입 | 주 3회 이상 | 자동화 안 함 (직접 촬영·편집) |
| 캐러셀(카드뉴스) | 팔로워 먼저 → 반응 좋으면 확산 | 저장·신뢰 | 주 2회 이상 | **이 봇이 전담** |
| 스토리 | 팔로워만 | 친밀감·전환 | 매일 2~3개 | 표지 리포트만 자동(`POST_STORY`), 나머지는 직접 |

릴스로 데려오고, 캐러셀로 믿게 만들고, 스토리로 가까워진다.
캐러셀을 자동화해서 번 시간은 릴스 대본에 쓰는 게 맞다. **조회수를 만드는 건 대본과 초반 2초 후킹이다.**

## 2. 콘텐츠 비율 4:3:2:1

봇이 `src/strategy/rotation.js` 로 자동 배분한다. 10개 기준:

- **도달형 4** — 신규 유입. 후킹을 가장 세게.
- **저장형 3** — 정보·꿀팁. 알고리즘 점수와 저장률 담당.
- **공감형 2** — 스토리. 댓글·신뢰 담당.
- **전환형 1** — 무료 자료 안내. 리드 확보 담당. 이때만 댓글 키워드 CTA가 붙는다.

한 유형만 반복하면 도달이 정체되기 때문에, 누적 비율에서 가장 뒤처진 유형이 다음 게시물이 된다.

## 3. 팔로워를 수익으로 잇는 깔때기

```
릴스(도달) → 프로필·고정글(신뢰) → 댓글 키워드 → 자동 DM(리드) → 커뮤니티(관계) → 유료 제안(전환)
```

이 봇은 세 번째 칸(댓글 → 자동 DM)을 `scripts/comment-to-dm.js` 로 처리한다.
설정은 `data/dm-templates.json`, 트리거 키워드는 `data/brand-config.json` 의 `cta.commentKeyword`.

**문구는 최소 3개를 넣어둔다.** 같은 문장이 반복 발송되면 스팸 패턴으로 잡힌다.
자료 링크(`resourceUrl`)를 비워두면 링크 없이 발송되므로, 켜기 전에 반드시 채운다.

켜는 법: 저장소 Variables 에 `COMMENT_DM_ENABLED=true`.
필요한 권한: `instagram_manage_comments`, `instagram_manage_messages`.

## 4. 계정 정지를 피하는 선

메타의 모더레이션은 콘텐츠뿐 아니라 **행동 패턴**을 본다. 이 저장소가 지키는 선:

- **공식 API만 사용.** 쿠키 스크래핑·비공식 자동화 앱은 정지 사유 1순위다. 인스타 트렌드 조사도 내 계정으로 로그인하지 않는 Apify를 쓴다.
- **발행 상한.** 하루 3건, 최소 120분 간격 (`brand-config.json` 의 `publishing`). 워크플로가 겹쳐도 코드가 막는다.
- **같은 문구 반복 금지.** 후킹 유형·설득 원리를 매번 돌려쓰고, DM 문구도 여러 개를 순환한다.
- **저작권.** 카드는 전부 우리가 렌더링한 타이포그래피다. 남의 사진·영상·음원을 쓰지 않는다.
- **광고 규정.** "무조건·보장·100%" 같은 단정 표현은 자동 검수에서 차단된다. 투자·건강 같은 민감 주제면 면책 문구가 자동으로 붙는다.

## 5. 주간 점검 3숫자

`npm run insights` (매일 자동 실행) 결과에서 볼 것은 세 개뿐이다.

1. **도달** — 얼마나 퍼졌나
2. **저장 수 / 저장률** — 5% 이상이면 알고리즘이 더 밀어주는 구간
3. **목적·후킹 유형별 성과** — 어떤 조합이 먹혔나

저장률이 높게 나온 유형은 다음 달 비중을 늘린다. 콘텐츠 30개가 쌓이기 전에는 조회수로 판단하지 않는다 —
알고리즘이 계정을 학습하는 구간이다.

## 6. 인스타 트렌드 조사 (Apify)

1. [apify.com](https://apify.com) 가입 (신용카드 없이 매달 5달러 무료 크레딧)
2. 계정 설정에서 API 토큰 복사 → 저장소 Secret `APIFY_TOKEN`
3. `data/topics-config.json` 의 `benchmarkAccounts` 에 벤치마킹할 **공개 계정** 아이디를 넣는다
4. `npm run trend-report` 로 반응 좋은 게시물과 자주 쓰인 해시태그를 확인한다

큐가 비면 봇이 여기서 주제를 뽑아 쓴다. **남의 캡션을 가져다 쓰지 않는다** — 주제 신호만 쓰고 문장은 새로 쓴다.
크레딧을 아끼려면 `resultsLimit` 를 20~30으로 둔다. 비공개 계정은 조회되지 않는다.

## 7. Claude Code + Codex 같이 쓰기

- 긴 작업(리팩터링·테스트·조사)은 Codex에 맡겨두고, 그동안 Claude로 다음 설계를 이어간다.
